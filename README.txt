# TypeKnight Auto Typer

## Overview
Finds words on screen and simulates keyboard inputs to type the word that was detected.

## Features
- Hotkey to start and quit the bot.
- Keyboard input simulation
- OCR word detection
- Computer Vision


## Technologies
- win32gui
- threading
- tkinter
- ttk
- keyboard
- time
- dxcam
- cv2
- pyautogui
- easyocr
- numpy
- enchant
- itertools
